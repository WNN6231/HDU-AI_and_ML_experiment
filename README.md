### 2025/2026 在 HDU 学习 AI 实验的项目汇总

本仓库旨在通过 Python 编程实现，加深对人工智能基础算法底层原理的理解。

* **技术栈**：侧重算法逻辑实现，不依赖黑盒框架，手撕 A* 与遗传算法。
* **实验重点**：状态空间搜索、参数调优（如 GA 的交叉变异率）以及对不确定性推理结果的对比分析。
* **个人经验**：AI 实验逻辑性很强，尤其是 A* 的启发式函数设计和遗传算法的收敛速度，稍微改个参数结果就天差地别😋。
    * 1. **建模**：先定义好状态空间和目标状态。
    * 2. **编码**：实现核心算法逻辑。
    * 3. **调优**：运行程序，根据输出结果调整超参数或启发因子。
    * 4. **可视化**：用 Matplotlib 绘制收敛曲线或搜索路径。
    * 5. **文档记录**：将测试数据和分析结果整理进报告。

## 实验开发流程
1. **算法定义**：明确问题的评价函数（如 A* 中的 $f(n) = g(n) + h(n)$）。
2. **数据结构**：构建 Open 表、Closed 表或种群个体编码方式。
3. **逻辑调试**：针对 8 数码问题的死循环或 TSP 问题的局部最优进行逻辑修正。
4. **性能验证**：测试不同规模数据集下的运行耗时与搜索深度。
5. **分析总结**：撰写实验报告，重点讨论启发式信息对搜索效率的影响。
